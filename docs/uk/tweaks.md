# Усі оптимізації OptimaX

[← На головну](../../README.md) · [English](../en/tweaks.md)

Список створено з коду програми (136 оптимізацій у 16 розділах, версія 6.4.3). Позначки: 🔴 впливає на звичні речі, 🟡 помірний вплив, 🔵 безпечно. «Відкат» — чи повертає OptimaX зміну до вашого початкового значення.

Перед застосуванням OptimaX перевіряє сумісність із вашим залізом і версією Windows: недоречне вимикається, шкідливе для вашого ПК (наприклад, вимкнення Game Bar на AMD X3D) блокується, а причина пишеться під пунктом.
