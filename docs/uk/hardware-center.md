| **Відеопам'ять** | Запис і звірка шаблонів у буферах відеокарти на вибраній карті |
| **Пам'ять** | Шість шаблонів у вільній частині оперативної пам'яті, «Діагностика пам'яті Windows» для повної перевірки |
| **Диски** | SMART / NVMe кожного диска («що диск повідомляє»), тест швидкості, вибіркове читання поверхні, перевірка файлової системи лише для читання («що підтвердила OptimaX») |
| **Монітор** | Роздільність, частота й масштаб кожного екрана, EDID, повноекранні кольори для пошуку битих і застряглих пікселів |
| **Ноутбук** | Батарея (паспортна й фактична ємність, знос, цикли), живлення, гібридна графіка, тротлінг з останнього тесту процесора |
| **Периферія** | Клавіатура, миша (кнопки й колесо), динаміки (лівий і правий канал), камера, мікрофон, мережеві адаптери |
| **Стрес-тести** | Лише CPU, лише GPU, CPU + GPU, RAM, VRAM, диск — з датчиками, графіками й аварійною зупинкою |
| **Фонові процеси** | Хто навантажував систему під час гри, збіг піків із падіннями FPS, що можна зробити; «Що обмежує продуктивність» і поради щодо андервольтингу |
| **Діагностика Windows** | Сині екрани, раптові вимкнення, TDR, WHEA, пристрої з помилкою драйвера; аналіз дампів через cdb.exe; SFC і DISM за підтвердженням |
| **Перевірка перед покупкою** | Покроковий майстер із 14 кроків і порівнянням із заявленою конфігурацією |
| **Звіти** | HTML, JSON, PDF, перегляд, історія, порівняння двох звітів |

## Статуси результатів

| Статус | Значення |
| --- | --- |
| **PASS** | Перевірку пройдено |
| **WARN** | Виявлено попередження (тротлінг, висока температура, знос, повільний диск) |
| **FAIL** | Виявлено проблему (помилки обчислень чи пам'яті, аварійна зупинка, несправний диск) |
| **SKIPPED** | Перевірку пропущено чи зупинено |
| **N/A** | Обладнання чи функція недоступні |

Під кожним результатом — знахідки простими словами, показники й графіки. Позначка «демо, не справжнє залізо» означає, що тест ішов на демо-залізі поза Windows і про конкретний ПК нічого не каже.

## Як влаштовані тести

- **Процесор.** Окремий процес рахує SHA-256 і BLAKE2b мегабайтного блока й стискає та розпаковує дані zlib. Кожен результат звіряється з еталоном (еталон — більшість із трьох обчислень), тож нестабільний розгін чи андервольт видно як «порахував неправильно», а не лише як «процесор завантажено». Частота береться з лічильника `% Processor Performance`, ліміт — з `% Performance Limit`, тепловий тротлінг — з `% Passive Limit` теплових зон. **Температура процесора** береться з програми датчиків, яка вже запущена, — Core Temp (спільна пам'ять, увімкнена за замовчуванням), HWiNFO («Shared Memory Support»), AIDA64 (спільна пам'ять) або LibreHardwareMonitor (Remote Web Server), — і в результаті видно, з якої. Без них OptimaX бере теплову зону ACPI й підписує її «ACPI»: на більшості настільних плат це датчик плати або стала (часто 27,8 °C), тож зона, що не змінюється під навантаженням, відкидається, а не показується як процесор. Без жодного джерела — «н/д», а не вигадане число. Це цілочисельне навантаження, не заміна Prime95 / OCCT з AVX.
- **Оперативна пам'ять.** Окремий процес займає частку вільної пам'яті (щонайменше 1,5 ГБ лишаються Windows), записує й звіряє шаблони: нулі, одиниці, шахівницю, біжучу одиницю, випадкові дані й номер блока в блоці (помилки адресації). Уся RAM недоступна програмі — для неї «Діагностика пам'яті Windows».
- **Відеопам'ять.** Окремий процес створює контекст OpenGL на вибраній карті, виділяє буфери по 64 МБ (поки не набере частку вільної VRAM або драйвер не відповість «пам'ять скінчилася»), для кожного шаблону записує всі буфери, копіює кожен засобами відеокарти в контрольний буфер і читає назад.
- **Диск.** Лише власний тимчасовий файл у `X:\OptimaX-DiskTest` без кешу Windows (`FILE_FLAG_NO_BUFFERING`): послідовні запис і читання блоками по 1 МБ, випадкові 4 КБ з однією чергою (IOPS, затримка). Перед тестом перевіряється вільне місце (після файлу лишається щонайменше 2 ГБ), файл і папка видаляються після тесту й при зупинці. Читання поверхні — 30 секунд читання випадкових ділянок фізичного диска, лише читання.
- **SMART / NVMe.** NVMe — журнал Health Information (критичні попередження, резерв блоків, знос, записано даних, години, увімкнення, аварійні вимкнення, Media and Data Integrity Errors). SATA — атрибути й пороги SMART (перепризначені, нестабільні, невиправні сектори, CRC, години, температура, записано). Для USB-дисків — лічильники надійності Windows.
- **Аварійна зупинка.** Під час стрес-тестів датчики читаються раз на секунду; процесор від 95 °C (програма датчиків або теплова зона, що змінюється) чи відеокарта від 92 °C три секунди поспіль зупиняють усі тести, а результат — FAIL.
- **Зупинка й таймаути.** Кожен тест — окремий процес: зупинка просить його завершитися (і прибрати за собою), через 8–10 секунд процес знімається примусово. Збій під навантаженням не закриває програму, а показується як «аварійне завершення».

## FPS-оверлей

Вмикається в Hardware Center → FPS-оверлей. Показує FPS, 1% і 0.1% low за останні 10 секунд, час кадру, завантаження й температуру процесора та відеокарти; розширений вигляд — ще частоти, відеопам'ять, пам'ять, споживання, відеокарту, що малює гру, режим показу (PresentMode) і графік часу кадру.

- **Без ін'єкції.** Кадри дає PresentMon (ETW), а оверлей — окреме прозоре вікно: завжди зверху, пропускає кліки, не забирає фокус і не з'являється в Alt+Tab. У процес гри OptimaX нічого не вбудовує, тож античитам нема що бачити, але сумісність із кожним античитом окремо ми не гарантуємо без перевірки.
- **Монопольний повноекранний режим** (PresentMode «Hardware: Legacy Flip») зовнішнє вікно перекриває — OptimaX це помічає й радить безрамковий режим. Якщо після появи оверлея гра перейшла з Independent Flip у Composed, OptimaX повідомить один раз.
- **Гра визначається сама**: вікно на передньому плані, процес якого є в бібліотеці, «Моїх іграх» чи знайдених іграх, або невідома програма на весь монітор (окрім браузерів, провідника, плеєрів). Є білий і чорний списки.
- **Гарячі клавіші** (на вибір, з перевіркою, чи не зайняті): Ctrl+Shift+F10 — показати / сховати, Ctrl+Shift+F11 — почати / зупинити запис сесії.
- **Запис сесії** зберігає CSV з кадрами й JSON зі звітом у `%APPDATA%\OptimaX\sessions`: FPS, 1% / 0.1% low, фризи, датчики, фонові процеси й висновок «що обмежує продуктивність».
- Оновлення чисел — 4 рази на секунду, датчиків — раз на секунду; навантаження самої OptimaX показано в налаштуваннях оверлея.

## Перевірка ПК перед покупкою

14 кроків: характеристики → відповідність заявленому (процесор, відеокарта, пам'ять, диски — впишіть, що обіцяє продавець) → процесор → відеокарта → відеопам'ять → пам'ять → стан дисків → швидкість диска → батарея (ноутбук) → екран → клавіатура → камера, мікрофон і звук → комбінований стрес-тест → підсумок і звіт.

Крок бере результат тесту, зроблений після початку перевірки, тож старі заміри не підмішуються. Візуальні кроки позначаєте ви. На ноутбуці з двома відеокартами крок «Відеокарта» потребує двох тестів — дискретної й вбудованої — і пройдений, лише якщо дискретна карта справді малювала під навантаженням: мертва чи вимкнена дискретна карта — найчастіший обман із вживаними ноутбуками.

## Звіти

HTML (з графіками), JSON і PDF (засобами Qt, без нових залежностей). Звіт містить залізо, BIOS, диски зі SMART, температури під навантаженням, результати тестів, помилки й попередження, графіки, підсумковий статус і рекомендації. Назва комп'ютера додається лише за позначкою, ім'я користувача й шляхи профілю замінюються, серійних номерів OptimaX не збирає. Історія звітів — в `%APPDATA%\OptimaX\reports`; два звіти можна порівняти (статуси й зміна балів у відсотках).

## Безпека

- Жодних руйнівних тестів дисків, форматування чи запису поза власним тимчасовим файлом.
- Жодних змін BIOS, напруги чи андервольтингу — лише поради з поясненням, чому і як перевірити стабільність.
- Жодного автоматичного завершення процесів: фонові процеси лише показуються, з варіантами дій для людини.
- SFC, DISM і chkdsk — лише після підтвердження (chkdsk — без ключів, лише читання).
- Налаштування «Графіка» Windows для GPU-тесту — лише за згодою й через журнал відкату.
- cdb.exe і PresentMon не встановлюються без вашої згоди (cdb OptimaX лише шукає).

## Обмеження

- **cdb.exe у складі OptimaX немає.** Аналіз дампів працює, якщо встановлено Debugging Tools for Windows (Windows SDK); без нього — розбір за кодом помилки на сторінці «Чому впав комп?».
- Температуру ядер Windows без драйвера датчиків не віддає: запустіть Core Temp, HWiNFO, AIDA64 чи LibreHardwareMonitor — OptimaX візьме її звідти; інакше — теплова зона ACPI (з підписом) або «н/д».
- **Датчики NVIDIA** — тієї карти, яку тестують (вибраної для тесту, а в оверлеї — тієї, на якій малює гра), а не першої NVIDIA на шині: у збірці GT 710 + P106 раніше це була GT 710.
- Відеопам'ять і оперативна пам'ять перевіряються частково (частину займають Windows, драйвер і програми).
- Мережа по процесах без ETW недоступна — у «Фонових процесах» вона показана для всієї системи.
- Колірне охоплення — оцінка за координатами з EDID, а не замір колориметром.
- Тести на реальному залізі (P106-100, Intel HD, Optimus-ноутбуки, AMD Hybrid) мають пройти на відповідних ПК; у CI все перевіряється на демо-залізі, Mesa OpenGL і Windows Server без GPU.
