# Часті питання

[← На головну](../../README.md) · [Посібник](guide.md) · [Усі оптимізації](tweaks.md) · [Часті питання](faq.md) · [Для розробників](development.md) · [English](../en/faq.md)

**Навіщо права адміністратора?** Зміни в HKLM, службах, bcdedit, powercfg і лічильники PresentMon без них неможливі.

**Чи потрібне перезавантаження?** Частина змін діє одразу, частина — після перезавантаження; такі пункти позначені, а кнопка перезавантаження з'являється в консолі.

**Чи можна все повернути?** Так: кожну зміну — у «Резервних копіях», пробні зміни — одним рішенням після перезавантаження, усю систему — через точку відновлення.

**Після оптимізації Windows не завантажується. Що робити?** Завантажтеся в безпечний режим і запустіть `C:\ProgramData\OptimaX\rescue\OptimaX-Rescue.cmd` — покроково в розділі [«Аварійний відкат»](guide.md#аварійний-відкат). Якщо Windows завантажується, але падає, OptimaX сам запропонує відкотити останній пакет змін.

**Чому розумна оптимізація прибрала твік, який «мав допомогти»?** Бо на вашому ПК з ним FPS був нижчим, ніж без нього, і різниця більша за розкид замірів. Його завжди можна застосувати вручну в експертному меню.

**Звідки береться PresentMon?** Це відкритий інструмент Intel (MIT). OptimaX завантажує консольну версію з офіційних релізів GameTechDev/PresentMon на GitHub лише після вашого підтвердження.

**Чому пінг міряється не через ping?** Більшість ігрових компаній не відповідають на ICMP-ping, тому OptimaX міряє час TCP-з'єднання з дата-центрами, де працюють ігрові сервери.

**Чому на моєму ПК деякі пункти недоступні?** OptimaX вимикає те, що не підходить вашому залізу чи версії Windows (наприклад, налаштування NVIDIA без відеокарти NVIDIA, пункти Windows 10 на Windows 11) або шкодить йому (Game Bar на AMD X3D). Причина написана під пунктом.

**Чому SmartScreen пише «Невідомий видавець»?** Інсталятор не підписаний цифровим сертифікатом. Натисніть «Докладніше → Виконати в будь-якому разі» або підпишіть збірку своїм сертифікатом (розділ [«Підпис коду»](development.md#підпис-коду)).

**Як оновити портативну версію?** Завантажте новий файл із релізу й замініть старий — налаштування лежать окремо в `%APPDATA%\OptimaX`.

**Чи безпечний стрес-тест?** Він навантажує відеокарту так само, як важка гра, а захист від перегріву в самій відеокарті працює завжди. Зупинити тест можна в будь-який момент клавішею Esc. На ноутбуках краще тестувати від мережі й на рівній поверхні.

**Чому мій результат у GPU-тесті не схожий на 3DMark?** Це інша сцена й інший API (OpenGL). Бали OptimaX призначені для порівняння вашого ПК «до і після», а не з таблицями інших бенчмарків.

**Що буде з інтернетом, якщо фільтр реклами зупиниться?** Windows сама перейде на резервний DNS роутера (крім суворого режиму), а OptimaX під час запуску перезапустить фільтр. Вимкнення фільтра повертає ваші попередні DNS.

**Сайт чи гра перестали працювати після блоку реклами?** Відкрийте «Блок реклами» → «Журнал запитів», знайдіть заблокований домен і натисніть «Дозволити», або поставте фільтр на паузу на 5 хвилин, щоб перевірити.

**Як захистити телефон і телевізор?** Увімкніть «Захищати всю домашню мережу» і вкажіть IP цього ПК як DNS у роутері або в налаштуваннях Wi-Fi пристрою. Це працює, поки ПК увімкнений, тож другим DNS у роутері краще вказати звичайний сервер.

**Працює на Windows 10?** Так, з версії 1809. Пункти лише для Windows 11 на Windows 10 пропускаються, і навпаки; так само ховаються параметри, яких ще немає у вашій збірці. На старіших збірках Windows 10 інсталятор попередить, що їх не перевіряли, і дасть вибір, ставити чи ні.

**Антивірус чи SmartScreen свариться на OptimaX. Це вірус?** Ні. Програми, зібрані PyInstaller, антивіруси часто позначають «про всяк випадок», а OptimaX ще й змінює реєстр і служби — саме те, що антивіруси стережуть. Увесь код відкритий у цьому репозиторії, а релізи збирає GitHub Actions прямо з нього; контрольні суми файлів — у `SHA256SUMS.txt` поруч із релізом (`Get-FileHash OptimaX-Setup-<версія>.exe` у PowerShell).

**Комп раптово перезавантажився чи показав синій екран. Як дізнатися чому?** Діагностика → «Чому впав комп?» → «Перевірити»: OptimaX прочитає журнал Windows і пояснить, що сталося, що найчастіше винне і що зробити, а якщо в цей момент працювала гра — назве її. Якщо підозра на пам'ять — там же «Перевірити пам'ять».

**Чи безпечний монітор на телефоні?** Сторінка лише показує показники — керувати ПК з неї не можна. Вона доступна тільки з домашньої мережі й лише за посиланням із секретним кодом («Новий код» робить старе посилання недійсним), а правило брандмауера діє лише для приватних мереж і прибирається, коли монітор вимкнути. Через інтернет сторінка не відкривається.

**Скільки коштує?** Нічого. OptimaX — відкрите ПЗ під ліцензією MIT: можна користуватися, змінювати й поширювати.

**Знайшли помилку або маєте ідею?** Налаштування → «Повідомити про проблему» відкриває issue на GitHub з уже заповненими версією й системою (без імені користувача й особистих шляхів), або відкрийте [issue](https://github.com/hatogg/OptimaX-by-X44TO/issues/new/choose) самі. До звіту про помилку додайте «Звіт для форуму» (Діагностика → Звіт) — там залізо, версія Windows і застосовані зміни, без особистих даних.
